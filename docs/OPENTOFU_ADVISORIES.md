# OpenTofu profile advisory assessment — 2026-10-16

Official OpenTofu 1.13.1 is built with Go 1.27.1; its exact source is [233700b795b6d2372f1c56ed57a4abaec9d36475](https://github.com/opentofu/opentofu/tree/233700b795b6d2372f1c56ed57a4abaec9d36475). This assessment covers local-backend initialization, validation, plan and apply with normal verified outbound HTTPS and local provider AutoMTLS enabled. It does not cover arbitrary remote backends, credential/login helpers, custom plugins or disabling plugin TLS.

Binary govulncheck emits 16 advisory IDs, recorded in the [per-ID assessment](../security/provider/opentofu-advisories.json). Twelve were published October 8. The sole critical issue among these, [GO-2026-6612](https://pkg.go.dev/vuln/GO-2026-6612), requires an HTTP/2 server processing malicious client streams. This profile opens outbound HTTP clients and uses private local provider RPC; it does not expose an HTTP/2 server. [Provider client setup](https://github.com/opentofu/opentofu/blob/233700b795b6d2372f1c56ed57a4abaec9d36475/internal/command/meta_providers.go#L39) enables AutoMTLS unless explicitly disabled. Do not disable it. Other October 8 advisories and [grpc GO-2026-6443](https://pkg.go.dev/vuln/GO-2026-6443) published September 15 are recent noncritical findings and remain tracked rather than asserted fixed.

The three older binary matches are not imported affected packages. The complete `go list -deps ./cmd/tofu` for the exact upstream module lists 1,808 packages, reviewed for this assessment. It contains neither golang.org/x/crypto/openpgp nor golang.org/x/mod/sumdb nor golang.org/x/mod/sumdb/tlog. Provider signature verification instead imports [ProtonMail's maintained OpenPGP implementation](https://github.com/opentofu/opentofu/blob/233700b795b6d2372f1c56ed57a4abaec9d36475/internal/getproviders/package_authentication.go#L21). The [hash helper](https://github.com/opentofu/opentofu/blob/233700b795b6d2372f1c56ed57a4abaec9d36475/internal/getproviders/hash.go#L21) imports only the independent sumdb/dirhash package. Therefore [GO-2026-5932](https://pkg.go.dev/vuln/GO-2026-5932) (legacy OpenPGP) and [GO-2026-6179](https://pkg.go.dev/vuln/GO-2026-6179)/[6180](https://pkg.go.dev/vuln/GO-2026-6180) (Go module sumdb client/tile verification) do not apply to this engine's linked package graph. The Go compiler used to build a derivative provider is assessed separately.

No applicable critical or >=60-day medium/higher vulnerability was identified in this bounded engine profile on the assessment date. This does not make the binary advisory-free, qualify official provider binaries, or excuse future updates. Source/version/feature changes and newly aged advisories require reassessment. Per-ID primary dates and dispositions are recorded in [the checked-in assessment](../security/provider/opentofu-advisories.json).
