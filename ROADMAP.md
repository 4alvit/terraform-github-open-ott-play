# Roadmap

This roadmap covers 16 October 2026 through at least 16 October 2027.

- Preserve repository ownership, state identity and narrowly scoped access during imports and policy updates.
- Extend offline negative tests for repository protections, release gates and supplied secret validation.
- Track Terraform/provider updates and repeat actual TLS tests before extending the supported cryptographic profile.
- Improve complete-source coverage and documented security reasoning; establish access continuity when an authorized backup actually exists.

Discuss changes through public issues and pull requests. These are plans rather than completed features or guaranteed delivery dates.

## Non-goals

No automatic production apply, blanket administrator bypass, hidden state migration, storage of plaintext secrets in Git, or authority over repositories outside the declared inventory.
